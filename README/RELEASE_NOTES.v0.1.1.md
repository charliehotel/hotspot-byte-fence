# Hotspot Byte Fence v0.1.1

등록된 핫스팟의 접속 주소(BSSID)가 변경되었을 때 모니터링이 승인 대기로 멈추면서 안내가 없던 문제를 보강했습니다.

## 수정 사항

- 등록된 Wi-Fi 이름과 같지만 BSSID가 달라지면 기존 프로필 재확인 창을 표시합니다.
- 승인하면 기존 사용량과 설정을 유지하고 모니터링을 재개합니다.
- 취소한 후에도 메뉴의 ‘기존 핫스팟 다시 확인…’에서 다시 승인할 수 있습니다.
- 확인 도중 연결이 변경되거나 끊기면 이전 연결의 승인을 적용하지 않습니다.
- ‘Hotspot Byte Fence 정보’는 기존과 같이 앱 번들의 버전을 표시합니다. 패키징 버전의 원본인 빌드 매니페스트를 0.1.1로 갱신했습니다.

## 설치

Apple Silicon(arm64), macOS 13 이상이 필요합니다. 기존 앱을 종료한 다음 DMG 또는 ZIP의 앱으로 교체하세요. 기존 프로필을 다시 만들 필요는 없습니다.

- DMG: `HotspotByteFence-0.1.1.dmg`
- ZIP 및 앱 내 업데이트: `HotspotByteFence-0.1.1-unsigned.zip`
- 다운로드 검증: `SHA256SUMS.txt`

Developer ID 서명과 Apple 공증은 제공하지 않습니다. 설치 후 필요한 로컬 서명 절차는 [설치 안내](https://github.com/charliehotel/hotspot-byte-fence/blob/v0.1.1/README.md)를 참고하세요.

## 검증 범위

릴리스 빌드와 전체 자동화 테스트 137개가 통과했습니다. 앱 번들과 실행 파일의 버전이 모두 0.1.1임을 확인했고, 앱의 ad hoc 서명과 ZIP·DMG 무결성을 검증했습니다. 실제 핫스팟 전환 시 재확인 창과 시스템 알림 표시, Wi-Fi 차단 동작은 이번 배포 검증에 포함하지 않습니다.
